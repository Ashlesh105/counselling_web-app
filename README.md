## 🚀 How to Run the App

### Start Development Server
```bash
npm run dev
```
Open **`http://localhost:5173`** in your browser.

### Build for Production
```bash
npm run build
```
Creates an optimized production bundle in `/dist` that can be deployed to **Vercel, Netlify, Cloudflare Pages, or GitHub Pages** in 1 click!

### 🐳 Run with Docker
```bash
docker compose up -d --build
```
Open **`http://localhost:8080`** in your browser.
